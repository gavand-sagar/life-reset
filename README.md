# Life Reset

A 66-day habit-building PWA. Daily quests, XP and levels, streaks, a progress grid, and a journal. Fully local: all data lives in IndexedDB on your device, works offline, installable on mobile.

Live: https://life.sagar-gavand.co.in

## Dev
```
npm install
npm run dev
npm run build
```
Stack: React + Vite + TypeScript, Tailwind v4, Dexie (IndexedDB), vite-plugin-pwa.
